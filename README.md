# Data & AI — Bắt đầu từ đâu?

Slide cho buổi chia sẻ với sinh viên năm nhất ngành Khoa học dữ liệu & Trí tuệ nhân tạo — Trần Quang Huyên.

- Tiếng Việt: `deck-vi.html`
- English: `deck-en.html`

Mở file trong trình duyệt; dùng phím mũi tên, Space hoặc vuốt để chuyển slide. Thêm `#số` vào cuối URL để mở thẳng một slide.

## Sửa nội dung

Nội dung nằm trong `content/vi.json` và `content/en.json`. Sửa xong chạy:

```bash
python build.py
```

để tạo lại `deck-vi.html` và `deck-en.html`. Một câu hỏi có `"answer": []` sẽ hiện là "Trả lời trực tiếp tại buổi chia sẻ".

Nguồn ảnh: `assets/mad-paper-excerpt.jpg` trích từ Alemohammad et al., *Self-Consuming Generative Models Go MAD*, 2023 (arXiv:2307.01850).
